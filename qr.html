QR-Code

für die Rückmeldung auf euren Einladungskarten

So wirkt der Code auf dem Trennblatt. Größe und Lage legt ihr beim Druck fest.

Ist schon eingetragen, wenn ihr diese Seite über eure GitHub-Adresse öffnet. Nichts ändern.

Farbe des Codes

Karamell ist etwas dunkler als die Schrift auf der Karte, damit jedes Handy den Code sicher liest.

Für den Druck

  • Mindestens 2 × 2 cm groß drucken, besser 2,5 cm.
  • Dunkler Code auf hellem Papier, nicht umgekehrt. Hellere Töne wie das Sand der Ornamente reichen nicht.
  • Den weißen Rand um den Code frei lassen.
  • Den Probedruck mit einem iPhone und einem Android-Handy testen.
